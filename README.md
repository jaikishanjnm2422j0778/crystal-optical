# Crystal Optical – Eyeglasses & Sunglasses

A responsive e-commerce web page for an optical store, built with HTML, CSS and JavaScript.

## Features
- Responsive layout (mobile + desktop)
- Light/dark theme support
- Shopping cart with item counter
- Eyeglasses & sunglasses product listing

## Run locally
Open `index.html` in your browser.

## Live demo (GitHub Pages)
Repo → Settings → Pages → Branch: main / root → Save

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript
